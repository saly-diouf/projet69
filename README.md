# projet69 — Plateforme web d'études de marché

Plateforme web d'études de marché avec enquêtes en ligne et analyses statistiques.

## Stack technique
- PHP + MySQL + Apache (XAMPP)
- HTML/CSS/JavaScript
- Chart.js pour les graphiques

## Installation
1. Copier le dossier dans `htdocs/`
2. Importer `database/schema.sql` dans phpMyAdmin
3. Accéder à `http://localhost/projet69/setup.php` pour créer les comptes
4. Se connecter avec les comptes par défaut
